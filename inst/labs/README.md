# 线性代数实验教程（ROpenEigen 版）

这套实验是教材《线性代数》（第三版，段正敏等主编，高等教育出版社，2019 年 8 月，
ISBN 978-7-04-052027-9）的**上机配套**，共 8 个实验，逐章对应教材第一至第六章，
最后加一个综合实验。

设计原则只有一条：**教材让你手算的每一步，这里都要在机器上重做一遍，并让机器自己
证明它做对了。**

于是每个实验都长成同一个样子：

1. 先用几行 R 把教材里的算例录进去，手算过程用代码展开（逆序数、按定义展开行列式、
   行最简形、Gram-Schmidt、配方法……）；
2. 再用 ROpenEigen 的库函数算同一个东西；
3. **两者必须对上**，对不上就停 —— `expect_near()` 会抛错。

第 1 步不是多余的仪式。教材上的「求秩」「求基础解系」「化标准形」都是算法，
算法在 R 里能一行行写出来，写出来才知道自己到底是会了还是背下来了。第 2 步则告诉你
工程上真正会怎么算，以及为什么那样算更快、更稳。

## 怎么跑

```bash
# 装好包之后（R CMD INSTALL ROpenEigen_0.2.0.tar.gz）
Rscript run-all.R              # 顺序跑完 8 个实验
Rscript run-all.R 01 03        # 只跑实验一、三
Rscript run-all.R --quiet      # 只要每个实验一行的摘要
Rscript lab05-eigen.R          # 单个实验直接跑

# 包已安装但不想找路径时
Rscript "$(Rscript -e 'cat(system.file("labs","run-all.R",package="ROpenEigen"))')"
```

唯一依赖是 ROpenEigen 本身，不需要额外装包。全部 8 个实验在本机合计约 0.2 秒跑完
（Eigen 是编译好的 C++，慢的是你的手算）。

每个实验都能单独运行：脚本开头的 `.lab_dir` 会自己定位所在目录并 `source("helpers.R")`，
所以 `Rscript` 和 RStudio 里 `source()` 都行，不依赖工作目录。它依次尝试三处：
脚本自身的路径（`--file=` 或 `source()` 写进 `ofile` 的那个）、当前目录及其上层的
包源码树（`<root>/inst/labs`）、最后才是已安装的包 —— 所以安装副本比源码树旧时
也不会跑错版本。

## 八个实验

下面每个实验只写三件事：**做什么**、**机器给出的关键数值**、**做完应该能回答什么**。
数值全部来自实跑，与教材手算结果一致的地方会注明。

### 实验零 · 熟悉 ROpenEigen（1 学时）

**做什么**：跑通环境；把教材上的矩阵正确录进 R；认识 `eigenMat` 这个不透明句柄；
看清 base R 的 `dim()`、`t()`、`det()`、`solve()`、`%*%` 在 ROpenEigen 对象上直接可用；
用 Hilbert 矩阵建立「数值零」的观念。

**关键数值**：8 阶 Hilbert 矩阵 `det = 2.737e-33`、`rcond = 6.55e-11`，
而 `H %*% solve(H) - I` 的最大偏差是 `8.196e-08` —— 行列式小到 1e-33，
逆却只准到 1e-8。这两个数字放在一起，就说明了为什么后面所有判断「等于」
都写成相对误差。

**做完能回答**：为什么 `matrix(c(1,2,3,4), 2, 2)` 和教材上的矩阵不是一个东西？
`eigenMat` 里装的是什么？为什么 `det(A) == 0` 这种写法在数值上几乎总是错的？

### 实验一 · 行列式（3 学时）

**做什么**：按定义算 3 阶行列式的 6 项（逐项列出排列的逆序数与符号）；
`det_by_definition()` 与 `eigen_det()` 对账；逐条验证 8 条性质；按行/按列展开、
代数余子式、伴随矩阵；§1.5 的几何应用；最后是数值陷阱。

**关键数值**：`τ(3421) = 5`、`τ(517924) = 7`；3 阶算例 `det = -3`（定义法与库函数一致）；
三角形面积 `6`、三平面交点 `(1, 2, 3)`；`|1e20·E20| = Inf` 而 `logdet = 921.034`；
Hilbert 矩阵 4/8/12/16 阶的 `det` 从 `1.653e-07` 掉到 `2.037e-135`。

**做完能回答**：为什么 n 阶行列式按定义要算 n! 项，20 阶就已经不可行？
`|MN| = |M||N|` 在浮点下还成立吗（成立，但误差会累积）？
为什么工程代码里几乎不直接算行列式？

### 实验二 · 矩阵（4 学时）

**做什么**：矩阵运算与特殊矩阵；`MN ≠ NM`、`AB = 0` 但 `A, B ≠ 0`；
分块乘法；用**枚举子式**按定义求秩；三种初等方阵与初等行变换的对应；
求逆的三种方法（伴随矩阵 / 初等变换 / 库函数）；克拉默法则；
§2.8 投入产出模型。

**关键数值**：三种求逆方法的相对误差 `7.1e-16` 与 `2.2e-17`；
投入产出：`|E - A| = 0.333`，总产出 `X = (236.6366, 235.4354, 186.7868)`，
农业最终产品增加 10 → 三部门总产出增加 `(15.6156, 6.9069, 4.2042)`。

**做完能回答**：为什么「农业多交 10 元最终产品」要求农业自己增产 15.6 元？
伴随矩阵法为什么在 n 稍大时就不能用？克拉默法则的复杂度是多少？

**这一节有个坑要专门看**：`solve(eigenMat(S))` 对奇异矩阵**不报错**，
而是返回 `NaN`/`Inf`。base R 的 `solve()` 会报错。所以实验里给了 `safe_inverse()`：
先查 `rcond`，再决定要不要解。这是本套实验里唯一一处「库函数比你想的更沉默」的地方。

### 实验三 · 向量组的线性相关性及线性空间（4 学时）

**做什么**：内积、长度、夹角、柯西-施瓦茨不等式（20 组随机验证）；
相关性判据与「系数从哪来」（零空间）；用行最简形的主元列找最大无关组并写出其余向量的表示；
Gram-Schmidt 正交化并与 `eigen_qr()` 对照；基、维数、坐标、过渡矩阵；
线性变换的矩阵表示与换基公式 `B = P⁻¹AP`；§3.7 多项式空间的内积与正交化。

**关键数值**：夹角 `53.3957°`；最大无关组 `{α1, α3}`，且 `α2 = 2α1`、`α4 = 2α1 + α3`；
§3.7 的 Gram 矩阵正好是 3 阶 Hilbert 矩阵，正交化结果是 `1`、`x - 1/2`、`x² - x + 1/6`
（移位 Legendre 多项式，已断言）。

**做完能回答**：为什么「向量个数大于维数必相关」？
换基公式里 `P` 的列到底是什么（是**新基在旧基下的坐标**，所以必须按列 `cbind` 拼，
写成 `byrow = TRUE` 就全错）？多项式空间里 `1, x, x²` 并不正交，正交化之后变成了什么？

**这一节的技术要点**：多项式空间的内积是**坐标的点积带权**，普通的 Gram-Schmidt
不适用（实验里 `q1'q2 = 0.0737 ≠ 0`）。`helpers.R` 为此提供了
`gram_schmidt_metric(A, G)`，判据改成 `Q'GQ = E`。

### 实验四 · 线性方程组（3 学时）

**做什么**：同解定理与三种情形的机器判定（唯一 / 无穷多 / 无解）；
齐次方程组的基础解系与解空间维数 `n - R(A)`；非齐次的特解 + 通解结构；
不相容方程组的最小二乘解；§4.4 食堂马尔可夫模型；化学方程式配平。

**关键数值**：食堂模型转移矩阵 `P = [[1/4, 1/3], [3/4, 2/3]]`，
稳态 `x* = (4/13, 9/13) = (0.3076923, 0.6923077)`，第 10 个月后已稳定到小数点后 6 位；
配平结果 `1 C_3H_8 + 5 O_2 → 3 CO_2 + 4 H_2O`，逐元素核对通过。

**做完能回答**：为什么齐次方程组「有非零解」等价于 `R(A) < n`？
`Ax = b` 的通解为什么是「一个特解 + 齐次通解」，而不是随便加？
为什么食堂问题最终会稳定，稳定值与初始分布有关吗（无关，只与 `P` 有关）？

**又一个坑**：对**超定**矩阵 `solve(eigenMat(A), b)` 返回的是**最小二乘解**，
不报错、也不提示。所以实验里专门打印了残差，让你看见「它其实没解出来，只是最接近」。

### 实验五 · 矩阵的相似对角化（4 学时）

**做什么**：`Av = λv` 验证、`tr = Σλ`、`|A| = Πλ`；用 Faddeev-LeVerrier 算法
手算特征多项式并与 `polyroot()` 对照；代数重数 vs 几何重数（Jordan 块为什么不能对角化）；
相似不变量；实对称矩阵的正交对角化（`Q'Q = E`、`Q'SQ = Λ`、还原误差）；
§5.4 差分方程动态模型与 Fibonacci；最后是 Wilkinson 式的数值警告。

**关键数值**：实对称算例 `[[4,2,2],[2,4,2],[2,2,4]]` 的特征值 `(0, 6, 6)`，
正交矩阵还原误差 `8.88e-16`，程序给的特征向量 `(1,1,1)/√3` 与教材一致（夹角余弦 `1`）；
差分方程 `VΛ⁸V⁻¹x₀` 与逐步迭代之差 `3.41e-13`；
Fibonacci 矩阵法与 Binet 公式都得 `F₁₀ = 55`，主特征值 `φ = 1.618034`。

**做完能回答**：为什么旋转 90° 的矩阵在实数域没有特征值？
为什么「代数重数 = n」不保证能对角化，还要看几何重数？
为什么 `A^k` 当 k 很大时，方向会趋于主特征向量？

**这一节最重要的警告**：友矩阵（特征值正好是 1…10）把特征多项式的一个系数扰动
`1e-8`，根的最大位移是 `2.214e-04` —— **放大了 22143 倍**。所以永远不要
「先展开特征多项式再求根」，正确做法是直接对矩阵做 QR 迭代（`eigen_geigen`
内部就是 Schur 分解）。这条在教材里通常只说一句「特征多项式在高阶时不好用」，
这里是把它量化了。

**另一处**：`eigen_eigen()` 是 **SelfAdjointEigenSolver**，只读**下三角**并假定对称。
拿它算非对称矩阵（如旋转矩阵）会给出错误结果 `(-1, 1)`；要算一般矩阵的（可能是复的）
特征值，用 `eigen_geigen()`，旋转矩阵得 `±i`。

### 实验六 · 二次型（4 学时）

**做什么**：二次型与对称矩阵的互相转换（`quad_matrix()` / `quad_eval()`）；
正交变换法化标准形；配方法；惯性定理（同一矩阵两种方法，惯性指数必须相同）；
正定性的四种判别法（顺序主子式 / 特征值 / Cholesky / 惯性指数）与一个综合判别函数
`classify_quad()`；§6.4 二次曲面分类；Hessian 矩阵与多元函数极值。

**关键数值**：教材 §6.3 例 1 的 `f = 5x₁² + x₂² + 5x₃² + 4x₁x₂ - 8x₁x₃ - 4x₂x₃`
在 `x = (1, -2, 3)` 处，矩阵法与代数式都得 `46`；正交变换后的特征值
`(0.101021, 1, 9.898979)`；同一矩阵 `B` 用配方法得标准形系数 `1, 1, 0`、
用正交变换得 `0, 1, 3`，但两边惯性指数都是 `(2, 0, 1)`；
例 2 的临界条件是 `a² - a - 1 = 0`，正根即黄金比 `1.618034`。

**做完能回答**：为什么标准形不唯一而规范形唯一？
顺序主子式全正为什么就等价于正定（和 Cholesky 分解有什么关系）？
为什么极值判别要看 Hessian 的特征值符号，而不是只看 `f'' > 0`？

### 实验七 · 综合实验（4 学时）

**做什么**：四个真实问题，每个都用前面六章的东西拼起来。

1. **SVD 图像压缩**：240×320 的合成图，按 Eckart-Young 定理验证「截断误差 =
   被丢掉奇异值的平方和开根」；`k = 20` 时误差 `2718.291`，压缩比 `6.84 : 1`。
2. **最小二乘曲线拟合**：正规方程 / QR / SVD 三种解法在良态下差 `1.98e-14`；
   换成 8 次多项式（`cond(X) = 690122`、`cond(X'X) = 4.76e11`）后，
   正规方程与 SVD 的解最大差到 `1.9e-4` —— 这就是为什么工程上不用正规方程。
3. **PCA**：协方差矩阵特征值 `(0.158568, 13.505229)`，解释方差比 `1.16% / 98.84%`，
   重构误差平方和除以 `n-1` 正好等于被丢掉的那个特征值。
4. **PageRank**：6 个页面的链接矩阵（含悬挂节点处理），`d = 0.85` 幂迭代收敛到
   `(0.065768, 0.090220, 0.111005, 0.065768, 0.342119, 0.325119)`，
   与「解线性方程组」得到的答案差 `4.1e-15`，排名 `5 > 6 > 3 > 2 > 1 > 4`。

**做完能回答**：压缩比和误差之间怎么权衡？`cond(X'X) = cond(X)²` 为什么是致命的？
PCA 的「解释方差比」到底在解释什么？PageRank 的收敛速度由什么决定？

实验末尾给了实验报告要求与三道附加题，可以当课程设计用。

## 三个贯穿全书的前提

实验零讲过，但后面每个实验都在用，这里再压缩成三句：

1. **按行写，按列填。** 教材的矩阵按行读，R 的 `matrix()` 默认按列填，
   所以一律写 `byrow = TRUE`。这一条错了，后面所有结果都错，而且错得「看起来像对的」。
2. **下标从 1 开始。** 教材 `a₁₁` 是 `A[1, 1]`，不是 `A[0, 0]`。
3. **判断相等用相对误差。** `relerr(a, b) < 1e-10`，不要写 `a == b`。

## `helpers.R` 里为什么有这些函数

教材要求「手算」的算法，ROpenEigen 作为数值库**故意不提供**（它给你的是 LAPACK 级
的成品），所以要么在实验里现写，要么就失去「看见算法」的意义。`helpers.R` 把
这些手算算法集中实现，每个都配一条与库函数的交叉验证：

| 函数 | 教材出处 | 作用 | 怎么验证 |
|------|----------|------|----------|
| `inversions(p)` / `permutations(n)` | §1.1 | 逆序数、全排列 | 与手算 `τ(3421) = 5` 对照 |
| `det_by_definition(A)` | §1.2 | `Σ(-1)^τ a₁ₚ₁…aₙₚₙ` | 与 `eigen_det()` 对照 |
| `cofactor_matrix` / `adjugate` | §1.4 | 代数余子式、伴随矩阵 | `B %*% adj(B) = |B|E` |
| `rref(A)` | §2.5 / §3.3 / §4.2 | 行最简形、秩、主元列 | 与 `eigen_rank()` 对照 |
| `nullspace(A)` | §4.2 | 基础解系 | `|A ξ| ≈ 0`，且列数 = `n - R(A)` |
| `particular_solution(A, b)` | §4.3 | 非齐次特解 | 代回 `Ax = b` |
| `charpoly_faddeev(A)` | §5.1 | Faddeev-LeVerrier 特征多项式 | 与 `polyroot()` 对照 |
| `poly_from_roots(r)` | §5.1 | 由根造多项式 | 与 `charpoly_faddeev` 互为逆 |
| `gram_schmidt(A)` | §3.4 | 普通内积正交化 | `Q'Q = E`，与 `eigen_qr()` 对照 |
| `gram_schmidt_metric(A, G)` | §3.7 | 带 Gram 矩阵度量的正交化 | `Q'GQ = E` |
| `quad_matrix(n, terms)` | §6.1 | `(i, j, 系数)` → 对称矩阵 | 与代数式在具体点上的值对照 |
| `quad_eval(A, x)` | §6.1 | 算 `x'Ax` | 同上 |
| `leading_minors(A)` | §6.3 | 顺序主子式 | 与特征值符号对照 |
| `inertia(A)` | §6.4 | 正/负/零特征值个数 | 两种标准形必须一致 |
| `safe_solve` / `safe_inverse` | §2.6 / §4.3 | 先查 `rcond` 再解 | 奇异矩阵能被拦下 |
| `matpow(A, k)` | §4.4 / §5.4 | 快速幂 | 与逐步 `%*%` 对照 |

其余（`say`、`expect`、`expect_near`、`relerr`、`projection_matrix`）是脚手架，
不属于教材内容。

## 数字从哪来

实验里出现的每一个数（行列式、秩、特征值、误差、迭代步数、压缩比）都是**实际运行**
的输出，不是从教材或参考答案抄的期望值。教材给的是手算算例，我们把它当输入重算一遍，
再和书上的答案对；对不上就查，查不出原因才怀疑书 —— 到目前为止都是自己算错。

写这套实验的过程中，被断言拦下来的典型错误有这么几个，值得提前说一声，免得你踩：
把过渡矩阵按行拼（`byrow = TRUE`）导致 `P⁻¹AP` 全错；多项式空间里直接套普通
Gram-Schmidt，忘了内积是带 Gram 矩阵的；§6.3 例 2 的行列式一度算成 `a³ - a - 1`
（正确是 `a² - a - 1`）；算 `VΛ⁸V⁻¹x₀` 时把复数特征向量用 `Re()` 截断，
重构结果差了 77。**这些错误都不会让程序报错，只会让数字悄悄错掉** ——
这正是每个实验都要写 `expect_near()` 和交叉验证的原因。

想核对某个实验：直接 `Rscript lab05-eigen.R`，屏幕上的输出就是基准。
